### OBSERVATIONS

Founder and full-stack engineer. I work across the whole stack of a company — product decisions, system architecture, and the code itself — not just one layer of it.

Currently running point on **Labuno**, an AI-native Laboratory Information Management System for labs across Bihar. The premise: labs run on paper logs, spreadsheets, and tribal knowledge — Labuno gives them a system that understands lab workflows on its own, from sample intake to results.

Outside of that — first-principles product thinking, algorithmic problem-solving in Python and C++, and frontend work where motion and typography actually earn their keep.
