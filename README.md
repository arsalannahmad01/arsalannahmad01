## Labuno

Diagnostic labs in India still run on register books, WhatsApp forwards, and one person who remembers how everything works. Labuno replaces that with a system that understands lab work on its own terms — sample intake, test panels, results, dispatch — and an agent layer that fills in the workflow, asks before it commits, and hands back to a human at the points that matter.

Built on **LangGraph** for durable workflow state and human-in-the-loop gates, with a **React / Tailwind / Framer Motion** front end. Starting with labs in Bihar.
